    HTML Vault

    Upload HTML files. Share them with a clean, opaque link.

    How to use this tool

    Uploading files

    • For a single HTML file: drag and drop an .html or .htm file onto the dropzone, then click Upload.
    • For multi-file presentations (slides with CSS, JS, images, video): package everything into a .zip file and upload it. The server extracts the ZIP automatically.
    • Maximum file size: 50 MB. Daily limit: 5 uploads per IP (resets at UTC midnight).

    Organizing a ZIP bundle

    • The ZIP must contain an index.html (or main.html) at the top level. This is the entry point for the presentation.
    • Place assets in subfolders and reference them with relative paths. Example structure:
    my-deck.zip
├── index.html          ← entry file (required)
├── style.css           ← custom styles
├── assets/
│   ├── runtime.js      ← slide runtime / scripts
│   ├── base.css        ← base deck styles
│   ├── fonts.css
│   ├── animations/
│   │   └── animations.css
│   └── themes/
│       ├── minimal-white.css
│       └── corporate-clean.css
└── media/
    └── video.mp4
    • Use relative paths in your HTML (e.g. assets/runtime.js, not /assets/runtime.js). The server serves all files from the bundle root.
    • If all files are inside a single top-level folder (e.g. my-deck/), the server strips that prefix automatically — no need to flatten.
    • Video files support HTTP range requests, so seeking works in the browser.

    Setting access tokens

    • Access tokens are passwords that protect your uploaded content. Viewers must enter a valid token to see the page.
    • After selecting files, expand the Access Protection panel. Click Add token for each file, enter a password, and optionally set a max visit count.
    • Set max visits to -1 for unlimited access, or a positive number to limit how many times the token can be used.
    • You can manage tokens later from the upload history sidebar — click the lock icon on any item.
    • Share the view URL along with the token password with your audience. Without the token, the content is inaccessible.
